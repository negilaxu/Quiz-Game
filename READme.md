# Quiz Game

A simple browser-based trivia quiz game built with HTML, CSS, and JavaScript.

## Features

- Fetches 10 medium-difficulty multiple-choice questions
- 10-second timer for each question
- Score is weighted by remaining time
- Immediate correct and incorrect answer feedback
- Confetti animation for correct answers
- Top 10 high-score leaderboard
- Responsive layout with no build tools required

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Start answering questions.

Because the game uses external APIs, an internet connection is required.

## APIs

- [Open Trivia Database](https://opentdb.com/) — Provides quiz questions
- Remote quiz scores API — Stores and retrieves leaderboard scores

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
